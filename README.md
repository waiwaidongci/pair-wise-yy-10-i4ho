# zfl-42 漆线雕阴干室交接簿

独立静态前端应用，直接打开 `index.html` 即可使用（无需构建、无外部依赖）。

## 三块结构

- `app/rules.js` —— **判定块**（纯函数）：柜位时段冲突、入柜异常、失重档位、复检与上金粉资格。
- `app/store.js` —— **存档块**：只追加的事件日志（localStorage），命令→校验→追加事件→重算投影；含导入导出。
- `app/app.js` + `index.html` —— **页面块**：只读投影、发起命令；每次渲染只做一次 `project()`，因此交接簿列表、待办队列与「从存档重算」结果一致。

## 业务规则

- **沿用当前作品**：首次启动自动迁移旧版 `zfl42Works` 作品档案；无旧数据则种三件示例。
- **柜位时段重叠只绑一件**：同柜位（半开区间，首尾相接不算重叠）或同一作品时段重叠都冲突。
- **整单退回、不留残单**：一单多条，任一条目冲突即整单拒绝，只落退单回执，不产生任何绑定。
- **重复投递读回原单**：每单一令牌（token），重复提交返回原回执（收/退同态），不追加事件、不重复建绑。
- **入柜登记**：初重、温度、湿度、责任人；温湿度越界或缺初重 → 只列待复检（可补初重后继续）。
- **复检**：复检必须换人，距上次称重隔满廿四小时；连续两次合规且失重比例同档（返潮/稳定/轻失/中失/急失五档）才可上金粉，否则续干。不合规复检留痕并标注原因。
- **履历变更**：胎体、纹样或柜位（移柜/改时）变更 → 在柜许可即止、按新值重算，旧入柜与称重条目快照留档，不参与新许可判定。
- **阈值可调**：温湿度允许范围在「履历存档」页调整，调整后全部条目按新值重算。

## 页面

- **交接簿列表**：按状态分组（可上金粉 / 待复检 / 待重新登记 / 续干中 / 待入柜 / 已上金粉 / 已注销），支持作品、状态、关键词筛选，卡片显示入柜信息、复检判定表与操作。
- **待办**：待入柜、待复检、复检到期、可上金粉，与列表同源同数。
- **履历存档**：作废许可留档、投递回执（含冲突原因）、只追加事件日志、判定参数、从存档重算一致性核对、事件存档导入导出。

## 测试

`node tmp/test.js` —— 判定+存档的端到端冒烟（43 项断言）：冲突整单退回、幂等读回、缺初重/越界、换人廿四小时同档、续干、上金粉闭环、变更留档、移柜改时、参数重算、重载一致性。
