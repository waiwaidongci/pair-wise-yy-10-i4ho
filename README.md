# zfl-42 小型漆线雕工坊管理

独立静态前端应用，直接打开对应 HTML 即可使用，无需构建。

## 工坊看板 `index.html`

- 新增作品并记录胎体、纹样、线条、贴线进度、阴干日期、金粉状态、缺陷和交付日期。
- 工序看板覆盖贴线中、待阴干、上金粉、待交付；含今日待阴干、缺陷作品、最近交付三类列表。
- 支持状态更新、缺陷记录、筛选排序、localStorage 持久化（键 `zfl42Works`）与 JSON 导出。
- 页头可进入「阴干室交接簿」。

## 阴干室交接簿 `drying.html`

沿用工坊看板当前作品（只读引用 `zfl42Works`，在顶部投放柜交接单）。代码分三块：

| 块 | 文件 | 职责 |
| --- | --- | --- |
| 判定块 | `rules.js` | 纯函数：温湿度越界、失重档位、复检判定、柜位时段冲突 |
| 存档块 | `store.js` | localStorage（键 `zfl42DryingLedger`）：整单原子投递、令牌幂等、复检/上金粉/变更落档、旧条目留档 |
| 页面块 | `app.js` + `drying.html` | 录入与展示，只调用前两块，不自实现规则 |

规则要点：

- **柜位时段重叠只绑一件**：半开时段 `[起, 止)`，同柜位与在柜绑定或同单草稿之间重叠即冲突。
- **冲突整单退回**：任何一条冲突，整单不写入、不留残单；冲突令牌也不登记，修正后可重用。
- **重复投递读回原单**：同一令牌第二次投递直接返回原交接单，不产生新单。
- **入柜登记**：每条写初重、温湿度、责任人。温湿度允许区间 18–28℃ / 50–75%；越界或缺初重的条目只列「待复检」，不连累同单其他条目。
- **复检与上金粉**：复检必须换人（非入柜责任人）；自阴干计时起，两次复检隔满 24 小时且连续两次失重比例同档（A <1%，B 1–3%，C 3–5%，D ≥5%）才可上金粉，否则继续阴干。缺初重的首次复检补录初重并开始计时；越界条目待复检环境恢复正常后开始计时。
- **履历变更**：胎体/纹样（作品库改动后点「同步作品变更」）或柜位时段变更，许可即止——旧条目整体留档（`archive`，不删除），生成新条目并按新值重算，旧复检一律不计入。
- **三块一致**：在柜列表、三栏待办、「重载校验」按钮均由同一份 state 经同一推导函数 `todos()/summary()` 得出；页内一致性标记实时核对 DOM 条数与推导计数。

首次打开会用作品库中的三件作品生成演示交接簿：一件已满足上金粉条件、一件入柜温度越界、一件缺初重。清除 localStorage 键 `zfl42DryingLedger` 可重新播种。
